ISSUE IDENTIFIED
================================================================================

The spin wheel was displaying incorrect results that didn't match the backend
result or align properly with the pointer.

Root Cause:
  The rotation calculation didn't account for the -90° visual offset used
  when drawing the wheel segments.

Symptoms:
  • Wheel stops at wrong segment
  • Result shows different multiplier than backend returned
  • Pointer doesn't align with displayed result
  • Balance might show incorrect amount

================================================================================
THE FIX
================================================================================

Issue Location: 
  File: /app/participant/dashboard/page.tsx
  Function: spinWheel()
  Lines: ~606-620 (rotation calculation)

Problem Code:
  ```javascript
  const segmentCenter = segmentIndex * segmentAngle + segmentAngle / 2
  const stopAt = 360 - segmentCenter
  const finalRotation = spins * 360 + stopAt
  ```

Fixed Code:
  ```javascript
  // Segments drawn with: start = i * STEP - 90 (visual offset)
  const segmentVisualCenter = segmentIndex * STEP + STEP / 2 - 90
  
  // Calculate rotation to align segment center with pointer (top = 0°)
  let stopAt = (360 - segmentVisualCenter) % 360
  if (stopAt < 0) stopAt += 360
  
  const finalRotation = spins * 360 + stopAt
  ```

Key Change:
  Added the -90° visual offset to the rotation calculation:
  `segmentVisualCenter = segmentIndex * STEP + STEP / 2 - 90`
  
  This accounts for how the SVG segments are actually drawn in coordinate space.

================================================================================
DETAILED EXPLANATION
================================================================================

Why the -90° Offset Matters:

The wheel segments are drawn with this formula:
  segment_start = i * STEP - 90
  segment_end = segment_start + STEP

This means in the SVG coordinate system:
  • Segment 0 is at: -90° to -50° (center: -70°)
  • Segment 1 is at: -50° to -10° (center: -30°)
  • Segment 2 is at: -10° to 30°  (center: 10°)
  • etc...

The pointer is fixed at the TOP of the wheel: 0°

To bring segment i's center to position 0° (under the pointer), we need:
  rotation = (360 - segment_visual_center) % 360

For example, Segment 7 (5x):
  • Visual center: 7 × 40 + 20 - 90 = 210°
  • Rotation needed: (360 - 210) = 150°
  • With 5 full spins: 5 × 360 + 150 = 1950°
  • Final visual angle: 210° + 150° = 360° = 0° (TOP) ✓

Old calculation (missing -90):
  • Center: 7 × 40 + 20 = 300°
  • Rotation: 360 - 300 = 60°
  • Total: 1800 + 60 = 1860°
  • Final: 300 + 60 = 360° (but should be at 210° offset)
  • WRONG! ✗
