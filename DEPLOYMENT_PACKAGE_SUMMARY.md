## 🎯 CRITICAL CONFIGURATION

### Before Deployment, You Need:

1. **Database Password**
   - Auto-generated by setup-vps.sh
   - Default: YourStrongPassword123!
   - Change in .env.local

2. **NEXTAUTH_SECRET** (32+ chars)
   - Generate: `openssl rand -base64 32`
   - Put in .env.local

3. **VPS IP Address**
   - Used for app URL
   - Used for database connection
   - Used for firewall rules

4. **Git Repository URL**
   - To clone your code
   - Set during first deployment

## 🆘 TROUBLESHOOTING

### If app won't start
```bash
pm2 logs praymid-app
npm run build
pm2 restart praymid-app
```

### If database connection fails
```bash
psql -U praymid_user -d praymid_db -h localhost
# Check if connection works
```

### If port is busy
```bash
lsof -i :3000
kill -9 <PID>
```
