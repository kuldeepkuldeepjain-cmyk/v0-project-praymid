📝 STEP-BY-STEP DEPLOYMENT:

  STEP 1: PREPARE YOUR VPS
  ─────────────────────────
  
    SSH into your VPS:
    $ ssh user@YOUR_VPS_IP
    
    Update system:
    $ sudo apt update && sudo apt upgrade -y
    
    Install Node.js (if not installed):
    $ curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
    $ sudo apt install -y nodejs
    
    Install pnpm:
    $ npm install -g pnpm
    
    Install PostgreSQL (if needed):
    $ sudo apt install -y postgresql postgresql-contrib
    
    Start PostgreSQL:
    $ sudo systemctl start postgresql
    $ sudo systemctl enable postgresql

  ─────────────────────────────────────────────────────────────────

  STEP 2: UPLOAD PROJECT
  ─────────────────────────
  
    From your LOCAL machine:
    $ cd ~/projects
    $ scp -r praymid/ user@YOUR_VPS_IP:/opt/
    
    (This copies the entire project to /opt/praymid on your VPS)

  ─────────────────────────────────────────────────────────────────

  STEP 3: CONFIGURE DATABASE
  ─────────────────────────────
  
    On VPS, create PostgreSQL database:
    $ sudo sudo -u postgres psql
    
    Then inside psql:
    > CREATE DATABASE praymid_db;
    > CREATE USER praymid_user WITH PASSWORD 'your_secure_password';
    > ALTER ROLE praymid_user SET client_encoding TO 'utf8';
    > ALTER ROLE praymid_user SET default_transaction_isolation TO 'read committed';
    > ALTER ROLE praymid_user SET timezone TO 'UTC';
    > GRANT ALL PRIVILEGES ON DATABASE praymid_db TO praymid_user;
    > \q
    
    Note your credentials for next step!

  ─────────────────────────────────────────────────────────────────

  STEP 4: SET ENVIRONMENT VARIABLES
  ─────────────────────────────────────
  
    On VPS:
    $ cd /opt/praymid
    $ cp .env.example .env.local
    $ nano .env.local
    
    Update with your values:
    
    DATABASE_URL=postgresql://praymid_user:your_secure_password@localhost:5432/praymid_db
    NODE_ENV=production
    NEXT_PUBLIC_API_URL=http://YOUR_VPS_IP:3000
    
    Save: Ctrl+O, Enter, Ctrl+X

  ─────────────────────────────────────────────────────────────────

  STEP 5: RUN DEPLOYMENT SCRIPT
  ─────────────────────────────────
  
    $ cd /opt/praymid
    $ chmod +x start-vps.sh
    $ ./start-vps.sh
    
    This will:
    ✅ Install dependencies
    ✅ Build the application
    ✅ Set up database schema
    ✅ Start the application

  ─────────────────────────────────────────────────────────────────

  STEP 6: VERIFY APP IS RUNNING
  ─────────────────────────────────
  
    Open browser and go to:
    http://YOUR_VPS_IP:3000
    
    If you see the login page → SUCCESS! 🎉
    
    Default test login:
    Email: admin@praymid.com
    Password: Check your database setup

  ─────────────────────────────────────────────────────────────────

  STEP 7: SETUP PM2 (KEEP APP RUNNING)
  ─────────────────────────────────────
  
    Install PM2 globally:
    $ sudo npm install -g pm2
    
    Create PM2 config:
    $ cat > /opt/praymid/ecosystem.config.js << 'EOF'
    module.exports = {
      apps: [{
        name: 'praymid',
        script: 'pnpm',
        args: 'start',
        cwd: '/opt/praymid',
        instances: 1,
        exec_mode: 'cluster',
        env: {
          NODE_ENV: 'production',
          PORT: 3000
        },
        error_file: '/opt/praymid/logs/err.log',
        out_file: '/opt/praymid/logs/out.log'
      }]
    };
    EOF
    
    Start with PM2:
    $ cd /opt/praymid
    $ pm2 start ecosystem.config.js
    $ pm2 save
    $ pm2 startup
    
    (This keeps app running 24/7, auto-restarts on crash)

⚠️  TROUBLESHOOTING:

  Q: App won't start
  A: Check DATABASE_URL in .env.local is correct
     $ pnpm dev (to see actual error)

  Q: "Port already in use"
  A: $ sudo lsof -i :3000 && kill -9 PID
     Or change PORT in .env.local

  Q: Database connection failed
  A: Verify PostgreSQL is running:
     $ sudo systemctl status postgresql
     
     Test connection:
     $ psql postgresql://user:pass@localhost:5432/praymid_db

  Q: Permission denied on scripts
  A: $ chmod +x *.sh

  Q: Module not found errors
  A: $ pnpm install (reinstall deps)
