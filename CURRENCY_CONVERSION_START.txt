Step 1: Add import at top of file
────────────────────────────────────
import { formatRupees } from "@/lib/format-utils"


Step 2: Find & Replace Patterns
────────────────────────────────────
FIND:    ${amount.toFixed(2)}
REPLACE: {formatRupees(amount)}

FIND:    ${amount.toLocaleString()}
REPLACE: {formatRupees(amount)}

FIND:    $${Math.abs(value).toFixed(2)}
REPLACE: {formatRupees(Math.abs(value))}


Step 3: Test
────────────────────────────────────
npm run dev
Check that amounts show with ₹ symbol
