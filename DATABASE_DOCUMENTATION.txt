========================================================================

1. participants (40+ columns)
   - All user account data, wallets, balances, referral system, KYC info
   - Auto-generated serial numbers (FLCN5001+)
   - Status tracking, activation, verification

2. mobile_verification_otps (7 columns)
   - OTP codes for mobile verification
   - Attempt tracking, expiry timestamps

3. payment_submissions (17 columns)
   - Activation/contribution payment submissions
   - Screenshot uploads, transaction tracking
   - Matching with payouts, rejection reasons

4. payout_requests (18 columns)
   - Withdrawal requests with all required fields
   - redirect_to_email and redirect_to_serial for admin pre-assignment
   - Matched contribution tracking, status workflow

5. transactions (11 columns)
   - Complete financial transaction ledger
   - Balance tracking before/after each transaction
   - Multiple transaction types supported

6. predictions (14 columns)
   - Crypto trading/prediction history
   - Leverage, profit/loss tracking
   - Timeframe and expiry timestamps

7. topup_requests (15 columns)
   - Wallet balance top-up requests
   - BEP20 address field for deposits
   - Confirmation and credit tracking

8. notifications (6 columns)
   - System and admin notifications
   - Read status tracking
   - User email indexed for fast lookups

9. activity_logs (6 columns)
   - Audit trail of user and admin actions
   - Actor information and target details

10. audit_logs (4 columns)
    - Admin-only action logging
    - Descriptions and timestamps

11. wallet_pool (6 columns)
    - Cryptocurrency wallet management
    - Balance and status tracking

12. invite_logs (7 columns)
    - Referral/WhatsApp invite tracking
    - Contact information hashing

13. user_contacts (6 columns)
    - Synced user contacts for invites
    - Unique constraint on user + phone

14. spin_coupons (9 columns)
    - Free bet coupons from spin wheel
    - Expiry and usage tracking
    - Linked to predictions

15. support_tickets (10 columns)
    - Customer support system
    - Status workflow and admin responses

16. gas_approvals (10 columns)
    - Blockchain gas fee approvals
    - Network and collection tracking

17. system_settings (7 columns)
    - Configuration values
    - Platform fees, limits, addresses

18. participant_sessions (6 columns)
    - Session management
    - IP and user agent tracking

19. payout_pre_assignments (5 columns)
    - Pre-assigned payouts before account creation
    - By serial number or email
